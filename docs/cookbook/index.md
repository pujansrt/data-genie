# Cookbook

Welcome to the Data-Genie Cookbook! This is a collection of high-value recipes for solving common real-world ETL problems.

## Featured Recipes

- **[CSV to PostgreSQL](/cookbook/csv-to-postgres)**: Efficiently stream large CSV files into a relational database.
- **[Idempotent SQL Sync (Upsert)](/cookbook/sql-upsert)**: Prevent duplicate data by updating existing records during insertion.
- **[S3 to RabbitMQ](/cookbook/s3-to-queue)**: Connect cloud storage to your message broker with minimal latency.
- **[Validation & Dead Letter Queue](/cookbook/validation-dlq)**: Handle dirty data by diverting invalid records to a separate file.
- **[PII Masking & Anonymization](/cookbook/pii-masking)**: Protect sensitive data (Emails, SSNs) during transmission for compliance.
- **[Parallel Processing](/cookbook/parallel-processing)**: Scale your throughput using multiple CPU cores for massive datasets.
- **[Multi-Sink Parallel Processing](/cookbook/multi-sink)**: Write to multiple destinations (e.g., File + Database) in a single pass.
- **[Real-time Web Dashboard](/cookbook/web-ui-dashboard)**: Use Job events to build a monitoring UI for your ETL pipelines.
